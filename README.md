# Quran recitation pack

The optional on-device recitation checker for the Quran app. The app downloads these files once, and from then on checking runs fully offline on the phone. No audio ever leaves the device.

| File | What it is |
|---|---|
| `recitation_int8.onnx` | The acoustic model: [rabah2026/wav2vec2-large-xlsr-53-arabic-quran-v_final](https://huggingface.co/rabah2026/wav2vec2-large-xlsr-53-arabic-quran-v_final), a CTC model fine-tuned on Quran recitation, exported to ONNX with input normalisation and log-softmax inside the graph and dynamically quantised to int8 (MatMul/Gemm only). Input `audio` float32 `[1, samples]` at 16 kHz; output `logprobs` `[1, frames, 56]`. |
| `ayah_tokens.json` | For each of the 6,236 āyāt, the model's tokens for every word, generated by code from the app's licensed Uthmani text (never typed by hand). A leading `-1` marks an optional token. |
